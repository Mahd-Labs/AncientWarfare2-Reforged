# AI use - Ancient Warfare 2: Reforged

**The code of this port was written largely by AI agents.** Claude models made by Anthropic, working as coding agents,
wrote most of the Java code, build scripts, resource converters and tests of this port, and most of its documentation,
from 13 November 2026 on. The project owner directed the work, set the rules, decided what to keep or drop, and
tested the results in game; other AI agents reviewed and tested the code as well. The private development history
recorded the agent on each change; the public repository starts from a single snapshot, and CHANGELOG.md lists the
changes.

What that covers:

- **Code.** The port re-implements the Minecraft 1.12.2 code of Ancient Warfare 2 (by Shadowmage, P3pp3rF1y,
  GotoLink and the AW2 contributors, GPL-3.0-or-later) against Minecraft 1.21.1 and NeoForge 21.1. The agents worked
  class by class from the original source, keeping its logic, names and data formats; the result is a modified version
  of the original code, not a clean-room rewrite. New code (conversion of 1.12 templates and worlds, the switchable
  improvements listed in the README, tests) was written by the agents.
- **Assets.** Textures, models, structures (templates), skins, sounds and translations are the original mod's, made
  by people (see CREDITS.md). No asset was generated by an AI image or audio model. Where vanilla Minecraft pixels had
  to be replaced, the new pixels were made by a small deterministic script that an agent wrote
  (`tools/licensing_replace_vanilla_copies.py`: noise, brick, plank and ring patterns), not by a generative model.
- **Text.** The changelog, README, these notices and most code comments were drafted by the agents.

What it means for you: the port is tested (automated GameTests, server and client start-up tests, world generation and
chunk save / load checks, internal test builds), but AI-written code can contain mistakes that a human
author would not make. Keep backups of worlds you care about. Report problems to <https://github.com/Mahd-Labs/AncientWarfare2-Reforged/issues>, not to the original
authors of Ancient Warfare 2, who have nothing to do with this port.
